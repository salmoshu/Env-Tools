# v0.7.50

- 组件安装状态、任务锁和日志按平台及 WSL 发行版区分，支持 Windows 与 WSL 同时更新同一个组件；同一目标上从组件管理或配额卡发起的重复更新仍会拦截。
- 账号切换失败提示与账号选择按钮垂直居中对齐。
- 组件管理右上角添加按钮使用居中的矢量加号。
- 主窗口与悬浮看板的重置机会文字支持悬停提示，按到期时间逐项列出完整本地日期及时间，区分 GLM 的 5h / 7d 卡片，保留同日到期的多次机会。接口明确无到期限制和未提供到期详情时分别显示对应说明。
- Codex 查询回退时保留仍有效且次数一致的到期详情；打包前检查 Shell 脚本换行，防止 WSL 执行含 CRLF 的脚本失败。

验证：Rust 全量测试、前端状态与日期回归测试、Vite 生产构建、Electron 主进程语法检查；Electron 界面回归使用模拟任务验证 Windows / 两个 WSL 发行版并发、独立结束与日志分流，以及两处对齐和主窗口 / 悬浮看板的到期提示。
