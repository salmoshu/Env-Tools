# v0.8.3

本版改进共享账号的额度估算口径，并修正用量分析的展开布局、年度活跃热力图与响应式速率标签。

## 额度估算

- 以服务商配额快照时间和已用百分比校准，本地统计采用请求级增量，不再把快照之后的请求计入旧快照。
- 滚动查询使用精确 elapsed，30 分钟桶仅用于缓存容差，不再代替真实窗口长度。
- 当前估算、历史高水位与快照缓存全部按 provider + account + window 隔离，避免同厂商账号串用。
- “全部来源”合并本机/WSL与已连接 SSH 设备的增量；支持直接查询 SSH 目标，来源不可用时在提示中明确标注。
- 没有已记录增量时回退服务商百分比，不再显示误导性的 `0 / ≈0`。

## 用量分析界面

- Token 速率卡片展开后精确铺满右侧内容区，不再遮挡左侧分析导航。
- 速率卡按实际可用宽度切换标签：窄卡只显示模型名称，宽卡显示 agent 与模型。
- 年度活跃移至用量趋势顶部，旧版保存的卡片顺序升级时自动迁移。
- 年度活跃热力格随卡片宽度同步调整宽高，始终保持正方形；窄窗口保留最小尺寸并支持横向滚动。
- 页头移入右侧内容列，左侧导航保持常规全高布局。

## 验证

- 前端回归测试 9 项通过，Rust 后端测试 74 项通过。
- Vite 生产构建通过。
- Electron 实测展开边界、宽窄窗口标签、卡片顺序、热力格尺寸及精确账号查询，控制台无错误。
