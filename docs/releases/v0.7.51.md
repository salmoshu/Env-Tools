# v0.7.51

- 统一重置和组件升级确认框的布局、图标、按钮层级与关闭行为；支持 Esc、键盘焦点约束、明暗主题和窄窗口。右下角通知增加状态图标、标题和分层正文，悬停或键盘聚焦时暂停自动消失。
- 主窗口与悬浮看板共用重置机会行。到期 hint 内常驻重置按钮，不受用量门槛限制；机会耗尽或数据为缓存时保留按钮并禁用。外层快捷按钮的出现门槛由 95% 调整为 80%，GLM 按接口实际提供的 5h / 7d 窗口分别判断。
- 确认重置后立即关闭弹框，在右侧按账号和窗口持续显示重置状态，完成后原位更新结果。关闭 hint、切页或配额刷新不会丢失状态，同一账号的重复入口在处理期间禁用。
- F5 在主窗口和悬浮看板中刷新数据，复用配额与会话分析刷新流程；抑制长按和在途重复刷新，配额未变化时也会正常结束刷新状态。
- 保留并完善按账号隔离的 Codex / GLM 重置到期日期缓存，支持重启恢复、缺失日期回填及过期清理。

验证：Rust 61 项单测、前端 6 项回归、Vite 生产构建、Electron 主进程与 preload 语法检查；使用完全模拟的数据完成 20 项 Electron 界面检查，覆盖提示入口、80% 门槛、F5、明暗主题、窄窗口与升级确认框。按要求跳过重置执行测试，未调用真实重置接口、未消耗重置机会。
