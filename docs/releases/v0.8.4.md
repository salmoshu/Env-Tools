# v0.8.4

本版将磁盘管理升级为 Jharu v1.0.0 同源专用实现，并优化共享账号、多设备场景下的 token 额度估算质量。

## 磁盘管理

- 补齐开发缓存、ML 模型、Python、构建目录、Git worktree、AI 工具、深度分析、重复文件、沙箱、系统空间、垃圾文件、桌面、浏览器、回收站、卸载器、进程、启动项、驱动器健康、空间历史、自动养护与悬浮挂件。
- 使用完整内容哈希、保留副本选择、删除前复核、运行态/锁检测和系统位置保护，替代旧的通用简化清理链路。
- 修复同头异内容文件误判、系统目录可勾选、还原点/Docker 动作语义、桌面与垃圾路径缺失等问题。
- 支持非 C 盘 Git，保护完整 Electron 进程树，并在首次启动时迁移旧养护设置与容量历史。

## 额度估算

- 识别“本机无增量、账号百分比却上涨”的其他设备或未知来源消耗；当前污染点不参与反推。
- 对污染窗口保留代际标记，避免本机随后恢复增长时误将同一窗口重新判为干净。
- 当前查询使用账号自己的 `fetched_at` 和精确 elapsed，不再以 10 分钟下限或相邻时间桶旧 token 代替当前窗口。
- 历史按账号、套餐、窗口代际与来源范围隔离；local、WSL、SSH 和 aggregate 不再混用样本。
- 扫描覆盖不足时拒绝当前样本；OMP/ZCode 使用请求级账号归因，旧缓存自动升级。
- 前端明确展示外部消耗、覆盖不足和低质量状态，保留客观估算边界。
