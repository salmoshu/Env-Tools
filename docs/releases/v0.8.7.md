# v0.8.7

## Token 速率

- 将前三张统计卡的部分宽度分给速率卡。普通宽度和最大化时显示项目、Agent、模型与速率，窄窗口才隐藏中间列。铺满的明细也明确标出最近使用的模型。
- 速率卡单独刷新最近活跃日志，约每 5 秒读取一次。Codex 新完成的请求由 usage 事件直接更新，不等待整个会话的平均值或后续 token_count。
- 速率来自已完成请求的实际时长，Codex 的日志计时可能包括首 token 等待。不会按 Fast 模式名称乘一个固定倍数。

## 套餐额度与周窗口

- 5h、7d 与月额度分别校准。只有 7d 窗口的 Codex 套餐也能显示额度。当前没有本地增量时，仍可使用同套餐的已校准容量。
- 按账号、套餐、重置窗口和数据来源比较观测 token 与服务商百分比的增量。对同段多个观测的配对斜率取中位数，再按重置窗口稳健汇总。百分比跳变、重置、百分比饱和或覆盖不足不再使整段历史失效。
- 配额卡区分服务商百分比、已观测 token 和估算等效额度，并注明估算区间及置信等级。
- 周窗口按账号显示自然周内的已观测用量及真实滑动 5h 峰值。参考线使用同账号当前套餐的 7d 和 5h 估算，没有对应窗口时不画该参考线。
