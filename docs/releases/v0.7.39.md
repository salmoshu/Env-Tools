# v0.7.39

- Codex 支持多个独立账号 profile：默认账号继续读取 `~/.codex`，新增账号由设置页创建并使用独立的 `CODEX_HOME`。
- Codex 配额按账号并行采集，5h / 7d 用量、套餐、重置额度和失败重试状态按账号隔离。
- 看板与用量分析使用自定义账号菜单：收起时仅显示账号名称，展开后才显示各账号的 5h / 7d 等窗口用量；套餐配额标题不再附加“全部来源合并”。
- Codex 配额重置操作携带当前账号 ID，避免误操作其它账号；账号凭证始终保存在各自 profile 的 `auth.json` 中。
- 所有厂商的默认账号与额外账号均支持新增、编辑、使用和移除；默认账号也可移除并恢复，操作仅改变注册状态，不删除磁盘凭证或会员配置。
- 账号选择改为后端统一保存的 active 状态，并即时同步到 Dashboard 与悬浮看板；受管 `codex` 启动器读取该状态，让后续新启动的 CLI 使用对应 `CODEX_HOME`，显式 `CODEX_HOME` 始终优先。
- Codex 安装/更新脚本为 Windows、Linux/WSL 安装每用户启动器并配置 PATH，不复制或覆盖其它账号的 `auth.json`；正在运行的进程不热切换。
- 设置侧栏“账户”更名为“Agent / 智能体”，主体按 Kimi Code、OpenAI Codex、GLM / BigModel、DeepSeek 分块管理账号、会员、登录和 API Key。
- Kimi Code、OpenAI Codex、GLM / BigModel、DeepSeek 均支持多账号；配额、错误、会员、登录或 API Key 按账号隔离，SSH 远端仅切换显示，不修改本机 active。
- 每个 Codex 账号可独立配置会员购买/续费日期与时长；默认账号沿用旧 `openai` 配置，额外账号使用 `openai:<账号ID>`，不会相互继承或覆盖。

验证：39 项 Rust 测试、Vite 生产构建、81 项 Electron 界面检查、42 项真实 Electron/IPC 联测、四家真实 HTTP 账号生命周期验收，以及启动器四入口共 92 项测试。另完成 Node 语法检查、真实 resolver 边界检查和 Git diff 空白检查。
