# v0.8.6

本版修复配额刷新、账号提示和磁盘清理，并改进窄窗口下的 Token 速率显示。

## 用量分析

- Token 速率卡空间不足时只显示项目和速率，空间充足时恢复 Agent 与模型。
- Codex 读取账号列表失败不再误报为切换失败。切换失败提示只显示在实际尝试切换的账号上。
- 配额刷新与会话分析分开。取数暂时失败时仍显示上次取得的配额，并标记为旧数据。
- GLM 卡片移除 Start Plan 通道，保留已订阅计划的配额。

## 磁盘管理

- 开发缓存清理的确认与取消按钮等高。
- Docker 或其 WSL 发行版占用虚拟磁盘时，保留该项并提示如何解除占用。只需释放空间时，可使用「系统空间」中的 Docker 清理。
- 磁盘页文案跟随应用语言，侧栏不再显示「Env-Tools 存储空间洞察」标头。
