# v0.8.0

本版为磁盘管理（第三大导航区）的重大版本：Jharu（github.com/riponcm/Jharu，Apache 2.0）的 31 个功能模块完成 1:1 对齐，磁盘页从"只能看"变为完整的扫描 → 选择 → 清理 → 还原闭环。另对齐概览仪表盘并修复全页配色与按钮样式。

## 新增：Jharu 完整功能对齐

- **回收站**（bin.rs 移植）：枚举回收站真实条目，从 `$I` 元数据恢复真实文件名（含扩展名）；按清理日志（trash-log.jsonl，2 万条自动裁剪）区分"本应用移入（Safe）"与"你自己删除（Caution）"；范围清空（全部 / 超 30 天 / 仅本应用超 30 天）逐项复核删除时间戳，不符即跳过；单项还原自动重建缺失的父目录。
- **清理日志**：每次移入回收站都记录来源（开发缓存 / 系统文件夹 / ML 模型 / 自动养护等），日志中仍在回收站的条目可一键还原。
- **卸载器**（apps.rs 移植）：读取三个卸载注册表键，显示程序体积 + AppData 数据体积 + 版本/发布者，可运行程序自带卸载命令。
- **启动项**（startup.rs 移植）：Run / Run32 / RunOnce / Startup 文件夹 / 登录触发计划任务；开关读写 StartupApproved 标志（与任务管理器字节级一致：02=开、03+FILETIME=关）；安全软件、硬件驱动、Windows 组件拒绝关闭；影响估计与运行内存展示。
- **系统空间**（system_space.rs 移植）：休眠文件（含精简型判断与快速启动状态）、页面文件（WMI 用量）、系统还原点、组件仓库 WinSxS、Docker；管理员动作用固定 id 白名单 + 临时脚本 + UAC 提权，命令行永不拼接用户文本。
- **应用沙箱**（sandboxes.rs 移植）：扫描 `%LOCALAPPDATA%\Packages` 下 MSIX/商店应用私有目录（本机 128 包 / 1.7GB），按临时区 / 应用数据 / LocalCache 分级，已卸载应用的遗留数据单独标注。
- **自动养护**（autocare.rs 移植）：默认关闭的定时清理，只清理 Safe 且工具自动重建、多日未用、≥100MB 的缓存；移除前用最新事实复核；事件日志持久化。

## 新增：清理进度与取消

- 清理与回收站清空改为后台任务：每处理一项推送 `done/total/当前项名`，前端显示进度条与当前文件，可随时取消（已完成的保持不变、可从回收站还原）。
- 新端点 `/api/disk/clean/start|progress|cancel` 与 `/api/disk/bin/purge/start`；前端 400ms 轮询（Electron IPC 桥无法直连 SSE 的等价形态）。

## 新增：Authenticode 签名校验

- 启动项评级对可执行文件做证书链校验（Get-AuthenticodeSignature，底层 WinVerifyTrust）：有效签名显示签名者，未签名标注来源无法核验，自称 Microsoft/Google/Intel 等大厂但验签失败判为 Risky（防伪装）。注：Jharu 的 codesign.rs 为 macOS 专用，此项为 Windows 侧增强。

## 新增：概览仪表盘（Overview 对齐）

- 四统计 tile：系统盘可用 + 逐日趋势线、本应用已释放 + 最近六周柱、现在可安全清理、实时负载（CPU/内存 2 秒采样）。
- 驱动器圆环 + 满盘预测 + "最先满"标记；可清理量按 safe/caution/risky 三色堆叠，点击直达对应页。
- 系统盘 squarify 树图（Bruls 2000 算法 1:1 移植），复用最近一次根目录深度扫描的顶层快照。
- 最近清理批次（同源 2 分钟内合并），一键跳转回收站还原。

## 修复

- 磁盘概览配色错乱：卡片误用硬编码深色底，改为应用 `qcard` 设计令牌，明暗主题自动跟随。
- 全页按钮为浏览器原生样式：补充通用 `.btn` / `.btn-primary` 类（应用此前只有局部按钮样式）。
- 树图硬编码高饱和蓝改为主题蓝色梯度，浅色块自动使用深色文字。
- 侧栏分组副标题对比度偏低、趋势线黄色在浅色主题不可读等问题。

## 其他

- 新增依赖 `trash = "5"`、`winreg = "0.52"`（与 Jharu 同源方案，替代此前受 PowerShell 反斜杠转义困扰的实现）。
- 清理入口统一为 `clean_and_journal`（回收站 + 日志），旧的 `move_to_recycle_bin` 下线。
- 功能对齐清单见 `docs/jharu-parity.md`。
