# v0.7.40

- 统一智能体命名：Kimi 的 Agent 显示为 **Kimi Code**，厂商保留为 `kimi`，模型展示剥离供应商前缀（如 `kimi/k3.1-pro`）。
- Codex 配额错误卡可直接发起浏览器授权登录；环境不支持直接授权时才跳转设置，并定位到对应 Agent 账号。
- 登录进程完成后回传状态，设置页会显示登录成功或失败并自动刷新账号凭证和配额，不再停留在“网页授权已启动”。
- 自动获取的会员到期时间和时长回填到右侧输入控件，并保持禁用状态。
- 设置返回按钮改为 Kimi 风格的左向尖括号；组件管理在宽屏下使用三列网格，窄屏自动降为两列或一列。
- Codex 账号下拉菜单中的窗口名称去掉 `Window`，显示为 `5h` / `7d`。
- 修复 Codex wrapper 链接覆盖真实文件的安装风险。

验证：Vite 生产构建、Rust 全量测试、Electron 主进程语法检查、英文/中文设置布局和多账号登录流程回归。
