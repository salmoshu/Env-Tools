# v0.8.1

本版修复 Kimi 会员等级显示 unknown、DeepSeek 累计消费起始日漂移，并统一用量分析的 token 单位、收敛 WSL 发行版占位。

## Kimi 网页会话：卡内引导 + 重新授权

- 会员等级（Allegro 等）与月总额度只来自 kimi.com 网页接口，CLI 登录不包含这些信息；此前网页会话过期时卡片只剩 `plan=unknown`，错误又被归到"去登录"，无法修复。
- 后端新增 `POST /api/kimi/web-credential`：提交 refresh_token 后先向 kimi.com 验证换新 token，再取会员信息，成功后写入本机凭证（默认账号 `~/.kimi-code/credentials/kimi-web.json`，读取优先级高于 WSL 回退）；失败返回 `kimi_web_session_expired` / `kimi_web_network` / `kimi_web_missing_token` 等错误码。
- Kimi 卡片与悬浮看板新增内联提示：会话缺失/过期显示"重新授权 Kimi"按钮，网络类失败显示"重试"；弹窗内含打开 kimi.com、F12 → Local Storage 复制 `refresh_token`、粘贴验证三步。
- 网页授权失败不再重复生成 "Kimi Monthly Total" 错误卡，状态统一挂在 Kimi 卡片上。
- 错误映射保留服务端明细：401 的 `unauthenticated` / "Session expired. Please log in again." 会原样透出，网络错误与需要重新登录可区分。

## DeepSeek 累计消费起始日

- 根因：`since` 存在可被覆盖的状态文件里，解析失败/重建时会被重置为当天（本机实际为 2026-11-16，而跟踪始于 2026-10-24）。
- 新增只写一次的起始日标记 `deepseek-spend.json.started`；迁移时取 min(状态里的 since、状态文件创建时间、今天)，本机恢复为 **2026-10-24**。
- 状态文件改为临时文件 + rename 原子替换，并保留 `.bak` 备份；读取失败自动回退备份，另加锁文件避免多实例并发写坏。
- 说明：10-24 至 11-16 的余额净减少量当时未记录，无法事后补算，累计金额从修复时点继续累加；起始日期保持正确。

## 用量分析 token 单位

- 新增 `fmtTokens`：KPI、会话表、图表 tooltip、项目/模型用量统一显示 K/M/B（1 位小数），不再出现 `1,495,492,142` 这类裸大数字；请求数、金额、百分比保持原样。

## 项目分组排序

- 会话表按项目分组时，组间改为按组内最近活跃时间降序（新建或刚改动的项目置顶），同刻再按组 token、名称排序；"项目排行"仍保持 token 排行语义。

## 组件管理

- WSL 发行版由横排 chip 改为下拉框，只列可管理发行版（名称 · 版本），选项变更后仍写入 `tools.wsl-target` 并重新探测。

- 前端 7 项回归通过，Vite 生产构建通过。
